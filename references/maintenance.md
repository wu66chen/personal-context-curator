# 维护、冲突处理、检索和分享

## 更新事务（轻量、按需）

1. 用当前用户意图和授权范围定位根目录、索引、目标权威文件与相关派生摘要；没有文件权限就生成提案/替换文件，不声称已写入。
2. 以 `(主体/实体，语义属性，适用场景，有效时间区间)` 判断是否同一事实。用语义而非字符串查重。例如“练习电脑”和“蓝雀”可能指同一台设备，先据本人说明或设备记录核对别名。
3. 识别变化：新增、补充、替代、纠错、临时例外、并存、冲突、撤回。不能仅用最新时间戳自动覆盖旧事实。明确的用户纠正优先；不同时间或任务范围分别保留。区分陈述日期、核实日期与实际生效日。
4. 将新事实/状态写入唯一权威文件。只对影响后续理解的历史保留旧值与时间范围；如用户要求删除或旧信息本身错误，不作为过去真实状态保存。相关摘要删改旧值、索引仅更新必要链接。保留用户的手工注释和不相关内容。
5. 局部改动允许直接执行（明确写入授权且低风险），涉及不可逆删除、外发、受限信息、重构、大批量不确定合并则按实际范围确认。普通信息不得因为非关键字段缺失无法写入。
6. 最后检查最新文件的基准是否与读入时一致；若变化重新读并合并。宿主支持时用原子替换、既有本地版本工具。不要自动启用同步或向远端提交。多文件没有原子事务时，最小写入并逐项验证；报告失败和真实落盘状态。
7. 若无法落盘但能生成变更文件，输出含相对路径的完整修改文件；另提供 APPLY.md 说明基准版本/hash（可获取时）、新增/替换列表、冲突及应用注意。应用者先重新读本地最新文件、核对基准，不盲目覆盖；没有基准时只按内容人工/Agent 合并。只有应用核实后才能称本地已更新。

## 中转、迁移与恢复

- **先定去向，再交付原稿。** 在本次授权范围判断原稿、附件及截图的归属、接收者、用途和可读环境。普通、雇主和私人材料可能需要各自的工作区；敏感主题直接交回获准的受限位置，混合原稿按其中最严的范围处理。范围不足时可先交回用户自行脱敏的片段。凭据继续由凭据管理器或获准保管处保存。
- **中转是接收位置。** 按用途决定长期留存原件、保存必要摘录或仅记本人确认与日期。正式页引用将清理的中转文件时，先验证替代来源并修复入链，再按已授权处置旧件；目标更加敏感时，普通页只写允许公开的出处说明。清单、日志也只在该域保留最少信息。
- **权限按读取身份核实。** 限制目录继承可减少其他账户的读取范围。同一用户身份下的全权限工具仍可能读到私密文件。跨域检索、全文索引、临时文件、模型输入、导出和备份都应按实际宿主能力限制；若只能靠指令约束，如实说明。链接不能扩大访问范围，权限未知时不打开目标正文来试探。外发另核接收方、允许的载荷及授权。
- **迁移留下回退点。** 保存本次文件清单、内容或基准摘要及必要权限信息；在目的域验证内容、权限和依赖后才处理原件。重试只补未完成步骤。发生并发写入时重新读取相关文件、保留他人变更；无法可靠合并就交付待处理项。失败后若目标已再次变化，不用旧备份自动覆盖。
- **核对交付清单。** 对独立交付包，列出获准的相对路径，核对实际包中多出的条目、缺件和链接目标，再比较选定文件的内容。向已有笔记库增量交付时仅核对本次文件；重名但内容不同则比较基准和双方改动，保留无关笔记。
- **复原按域演练。** 在经授权的空目录恢复一小份含索引、事实页、原稿或附件的材料，检查引用、锚点、可读性和目标权限。记录“实际恢复通过”的范围。撤回时覆盖授权范围内的摘录、索引、导出及可控备份；留存的旧备份再次恢复时先应用撤回再开放使用。日志不复写已撤回正文。

## 改名与合并

1. **找全候选。** 在授权域读索引、主题正文和维护入口。以谁来读、要解决什么事、谁维护及多久更新为依据，列出旧页或小节到目标页及小节的对应关系。既看同名异物，也看异名同物。写下应保留的独有段落、手写说明、观测时间、来源、附件、未核实或已停用状态。只整理主题页时，原始回顾和历史快照可继续充当来源。
2. **先查引用。** 同时查谁指向旧页、旧页又指向哪里。包括索引、正文、历史与维护记录中的活动链接、图片、相对路径、文本形式的文件名、别名及标题锚点。历史记录中的原文件名可保留为当时的名称。获准域以外的来源可能还引用旧路径；不越权枚举或打开。若有已知外部依赖且不能同步修改，在原域保留最小跳转及必要的旧标题，或保留原路径作为主入口。无旧路径依赖时，可直接更新现有索引。只在旧称仍有检索价值时保留别名；本人无需对照表时省去额外清单。把同名旧文件改作另一个用途前，先排除旧引用误指。
3. **保全再切换。** 利用同域可恢复的版本或临时副本，核对基准。迁入目标页时保留有意义的原话、实际验证范围、适用主体、时间、来源和附件归属。只合并同义事实；多个旧页若都有「来源」「当前配置」这类标题，给目标小节可区分的名字，并逐条改指。重算从新页出发的相对附件、来源和交叉链接。新增入口验证通过后才退役旧正文。遇到并发变动按本页的更新事务处理。
4. **从读者入口验收。** 逐组核对迁移前后的独有内容和附件。检查入链、出链、片段和可见导航，并用至少一个日常问题从索引找到实际答案，例如「这台机装了哪个版本」或「这个账号如何发布」。以旧称再找一次。检索到旧文件名时区分历史引文、保留的跳转与真正的断链。确认重跑不会再造重复页，报告本次检验的实际范围及无法核查的已知依赖。验证失败时保留可用入口和回退点。

## 时效性

- 稳定历史事实一般无需定期验证；过去某时点发生过不代表当前仍适用。
- 系统版本、网络环境、当前项目、预算、近期计划等需要任务相关的时效判断；缺少确认日期或较久未确认时，先标注“截至已知日期”，影响结果才询问或请用户核实。
- 用户本人最新明确指令，且适用于当前任务，可覆盖长期规则在本任务的用法；除非用户明确长期改变，档案原规则不改。
- “计划购买”“考虑使用”“有兴趣”“曾经使用”不等于持有、安装、当前使用、长期偏好。要求变更前识别是否已发生。
- 用户明确表达有效截止日时，超过日期的临时状态不能用于当前结论；可保留为历史，除非不值得保存或要求撤回。无日期不得编造到期日。

## 体检清单（只读也可做）

| 检查项 | 判定与修复 |
|---|---|
| 当前状态冲突 | 同实体、同属性、同范围、同时间的不同当前值。能明确替代则修正；否则标待核实 |
| 同义重复 | 权威文件只保留一份，其他位置改链接；保留不同语境和具体事件 |
| 过时风险 | 易变字段缺乏近期确认，标待核实，不自动删除/覆盖 |
| 来源和时间 | 高影响条目有证据及必要时间；不把文件日期当字段日期 |
| 类型混淆 | AI 推测、临时指令、计划不可升级为事实/永久规则 |
| 导航与链接 | 路径真实、索引覆盖活跃文件；移除或修复失效链接，仅在权限域内 |
| 摘要一致 | 派生摘要与权威条目一致；不复制过多细节 |
| 授权 | 无秘密、无跨权限域读取/写入；索引不泄露受限信息 |
| 用户内容 | 不擅自改写手工叙事、删历史或迁移文件；没有实际需要不大规模重构 |
| 完成状态 | 写入已核实；无法执行列出未完成项；不虚构版本、文件或成功反馈 |

按严重程度简述：阻碍当前使用的错误；需要本人核实的问题；可选整理建议。普通文件更新只需局部检查，无需全库体检。全面体检按用户授权扩大范围，尽量用实际文件工具核对链接和差异，不自动联网。重复执行同一更新应不产生新重复条目；只有内容或确认状态变化才追加有意义的变更日志。

## 最小上下文包

用户要求交给另一个 Agent 时，明确任务、接收方/服务、允许的资料范围、是否仅供阅读。优先从当前权威文件选取必要片段，保留来源相对路径或安全标识、确认时间/范围、未知状态和必要规则。不得复制不相关档案、隔离区和密码等；不能靠提示文字实现真正权限控制。生成独立 Markdown/文件包时说明“这是截至某日的只读副本”，不要让接收方误认为能维护原库。上传/发送/连接外部服务属于另一个动作，需用户明确授权。

推荐导出说明：目的、适用范围、生成时间、使用限制（无对外传播授权、任务结束不继续使用）、内容与依据、待核实事项。该说明是行为约束，不是技术性的接收方保密保证。
